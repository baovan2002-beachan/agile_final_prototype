# Palette (decided with the team)

Team feedback: **no gradients**. **Red + white** are the two main colors — small elements red, everything else white.
Plain bright red was "too red / eye-hurting", so the primary is softened to **burgundy**.

| Role | Hex | Use |
|---|---|---|
| Primary (burgundy) | `#8A2538` | active nav, primary buttons, key numbers, icons |
| Primary tier 1 | `#A8343F` | secondary accents, charts |
| Primary tier 2 | `#CB7A83` | chart fills, soft accents |
| Primary tier 3 | `#F0D9DC` | tinted backgrounds, chips |
| Alert red (brick) | `#B52F37` (dashboard) / `#D61F26` (Stitch export) | overdue, high risk, sign out, notification dot |
| Ink | `#1A1512` | main text |
| Slate | `#73787A` | secondary text (use `#5E5658` where small text needs more contrast) |
| Line | `#ECE6E6` | borders |
| Track | `#F1EFEF` | progress/ring tracks |
| Background | `#F8F6F6` | page (cards are `#FFFFFF`) |
| Success green / warning amber | `#18794A` / `#8F5F00` | status only, never decoration |

Brighter "v2" red for reference: `#D61F26`, tints `#E4575C`, `#EE9396`, `#F7C9CB`.

Other colorways tried (not chosen): brown `#6E3319`/gold `#8B6B3A` — the team said the brown "isn't working";
navy `#1B4E8A`; forest `#2D5A3D`. HTML + PNG for each are in `reference/`.
